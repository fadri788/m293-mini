# M293 – Miniprojekt Mini Club

Schulprojekt Modul 293 (WISS): statische Website über den Mini Countryman.

## Struktur
```
index.html            Startseite
css/style.css         externes Stylesheet
img/                  Bilder (Logo, Artikelbilder)
assets/background/    Hintergrundbild Header
pages/member.html     Unterseite Mitglieder
pages/preise.html     Unterseite Preise
docs/                 Notizen, Wireframe, Moduljournal
```

## Anzeigen
`index.html` im Browser öffnen. Validieren mit https://validator.w3.org und https://jigsaw.w3.org/css-validator.

Die Bilder in `img/` sind Platzhalter und werden durch die Bilder aus dem Unterricht ersetzt.
